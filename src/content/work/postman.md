I was Technical Lead for Postman's newly formed Growth team, focused on user engagement and retention.

The standout was Collection Templates, a way to publish and import ready-made API collections, which pulled over 45,000 imports in its first three months and became a real onboarding on-ramp. I also shipped LLM-powered features that generated collections automatically from a user's code, set up the team's A/B testing process, and mentored the engineers on the team.
